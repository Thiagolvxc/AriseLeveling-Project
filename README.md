# Arise Leveling
Esta aplicación tendrá como proposito ayudar a las personas que quieran llevar el progreso de sus entrenamientos diarios.

## Características
- Ingresar información del entrenamiento diario
- Ver mediante gráficos el avance que lleva

## Dependencias
Como dependencias se utilizaron las siguientes:
- expo
- expo sqlite
- react native
- react navigation
- firebase
- jsdoc
